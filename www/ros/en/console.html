Install

Commands and files over USB

A terminal and a file manager for a device on a USB cable: see how it is, change its settings, join a Wi-Fi network, and copy files to and from its SD card and flash drive - no network, no app on the computer. It needs Chrome or Edge on a computer, and Reload OS newer than 1.5.5.

This browser cannot reach a USB serial port. Open this page in Chrome or Edge on a computer.

  1. Allow it at the device

    Settings › USB › Commands over USB: on. It is off on every device until its owner switches it on, and can be switched off again afterwards (or with set usb_console false from here).

  2. Connect it

    The socket Reload OS was installed through: the chip's own USB Type-C ("USB JTAG/serial debug unit" in the browser's list) or the UART socket ("USB Serial"). Install names it for each board.

Commands

Files

Commands

  • status, version, ip, apps, df
  • settings - every setting; settings brightness - one
  • set brightness 60, set autostart Clock, set kiosk_lock true
  • wifi join "Shop WiFi" PASSWORD, wifi leave
  • log off, restart, ls, rm, mkdir, mv

Good to know

  • Passwords and keys can be set, never shown
  • Opening the port restarts some boards: the page waits for them
  • A file is checked when it arrives and gets its name only then
  • Through a USB-serial chip (the UART socket) copies are slower
  • On the command line: tools/usbfile.py in the app kit's source tree does the same

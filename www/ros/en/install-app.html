Install an app over USB

An app is one .elf file, from Studio or the app kit. This page copies it onto a device on a USB cable - no SD card, no network. It needs Chrome or Edge on a computer.

This browser cannot reach a USB serial port. Open this page in Chrome or Edge on a computer.

  1. Allow it at the device

    Settings › USB › Install apps over USB: on. It is off on every device until its owner switches it on, and can be switched off again afterwards.

  2. Connect it

    Use the socket Reload OS was installed through: the USB Type-C socket of the chip itself ("USB JTAG/serial debug unit" in the browser's list), or the UART socket on a board that has a USB-serial chip ("USB Serial"). Install names it for each board.

  3. Pick the app and install

What the device does

  • It checks the whole file before it keeps it: an app built for another board, a damaged file or a copy that was cut short is refused, and the apps it had stay as they were
  • The app goes to apps/ on its flash drive; one of the same name is replaced
  • It restarts by itself, and the app is on the home screen

Good to know

  • Needs a Reload OS newer than 1.5.1; no account and no network needed
  • Opening the port restarts some boards: the page waits for them
  • Through a USB-serial chip (the UART socket) a large app takes minutes
  • Other ways to install: the app kit guide; the device's files and settings: Commands and files over USB

ติดตั้ง

คำสั่งและไฟล์ทาง USB

เทอร์มินัลและตัวจัดการไฟล์สำหรับเครื่องที่ต่อสาย USB: ดูสถานะ แก้ settings ต่อ Wi-Fi และคัดลอกไฟล์เข้าออก SD card และ flash drive ของเครื่อง - ไม่ต้องมีเครือข่าย ไม่ต้องลงโปรแกรม ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ และ Reload OS ที่ใหม่กว่า 1.5.5

เบราว์เซอร์นี้เข้าถึงพอร์ต USB serial ไม่ได้ เปิดหน้านี้ด้วย Chrome หรือ Edge บนคอมพิวเตอร์

  1. อนุญาตที่เครื่อง

    Settings › USB › Commands over USB: เปิด ทุกเครื่องปิดไว้จนกว่าเจ้าของจะเปิดเอง และปิดกลับได้ (หรือพิมพ์ set usb_console false จากหน้านี้)

  2. เสียบสาย

    ช่องเดียวกับที่ติดตั้ง Reload OS: ช่อง USB Type-C ของตัวชิป ("USB JTAG/serial debug unit" ในรายการของเบราว์เซอร์) หรือช่อง UART ("USB Serial") หน้า ติดตั้ง บอกช่องของแต่ละบอร์ด

คำสั่ง

ไฟล์

คำสั่ง

  • status, version, ip, apps, df
  • settings - ทุกค่า; settings brightness - ค่าเดียว
  • set brightness 60, set autostart Clock, set kiosk_lock true
  • wifi join "Shop WiFi" PASSWORD, wifi leave
  • log off, restart, ls, rm, mkdir, mv

ควรรู้

  • ตั้งรหัสผ่านและคีย์ได้ แต่ไม่มีคำสั่งไหนแสดงออกมา
  • การเปิดพอร์ตทำให้บางบอร์ดเริ่มระบบใหม่: หน้านี้รอให้เอง
  • ไฟล์ถูกตรวจเมื่อมาถึงครบ และได้ชื่อจริงตอนนั้น
  • ผ่านชิป USB-serial (ช่อง UART) คัดลอกช้ากว่า
  • บน command line: tools/usbfile.py ใน source tree ทำได้เหมือนกัน

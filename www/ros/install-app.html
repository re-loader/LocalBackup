ติดตั้ง

ติดตั้งแอปทาง USB

แอปคือไฟล์ .elf ไฟล์เดียว จาก Studio หรือ app kit หน้านี้คัดลอกไฟล์ลงเครื่องที่ต่อสาย USB อยู่ - ไม่ต้องใช้ SD card ไม่ต้องมีเครือข่าย ใช้ Chrome หรือ Edge บนคอมพิวเตอร์

เบราว์เซอร์นี้เข้าถึงพอร์ต USB serial ไม่ได้ เปิดหน้านี้ด้วย Chrome หรือ Edge บนคอมพิวเตอร์

  1. อนุญาตที่เครื่อง

    Settings › USB › Install apps over USB: เปิด ทุกเครื่องปิดไว้จนกว่าเจ้าของจะเปิดเอง และปิดกลับได้เมื่อเสร็จ

  2. เสียบสาย

    ใช้ช่องเดียวกับที่ติดตั้ง Reload OS: ช่อง USB Type-C ของตัวชิปเอง (ในรายการของเบราว์เซอร์ชื่อ "USB JTAG/serial debug unit") หรือช่อง UART บนบอร์ดที่มีชิป USB-serial ("USB Serial") หน้า ติดตั้ง บอกช่องของแต่ละบอร์ด

  3. เลือกแอปแล้วติดตั้ง

เครื่องทำอะไร

  • ตรวจทั้งไฟล์ก่อนเก็บ: แอปที่ build ให้บอร์ดอื่น ไฟล์เสีย หรือการคัดลอกที่ขาดกลางทาง จะถูกปฏิเสธ และแอปเดิมในเครื่องยังอยู่เหมือนเดิม
  • แอปไปอยู่ใน apps/ บน flash drive ของเครื่อง แอปชื่อเดียวกันจะถูกแทนที่
  • เครื่องเริ่มระบบใหม่เอง แล้วแอปจะอยู่บนหน้าหลัก

ควรรู้

  • ต้องเป็น Reload OS ที่ใหม่กว่า 1.5.1 ไม่ต้องมีบัญชีและไม่ต้องมีเครือข่าย
  • บางบอร์ดเริ่มระบบใหม่เมื่อเปิดพอร์ต: หน้านี้รอให้
  • ผ่านชิป USB-serial (ช่อง UART) แอปขนาดใหญ่ใช้เวลาหลายนาที
  • วิธีติดตั้งแบบอื่น: คู่มือ app kit

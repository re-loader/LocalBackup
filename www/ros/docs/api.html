API reference

Everything in ros.h that an app can use: 292 functions and variables the firmware exports, and the header's types, constants and macros - from the app kit of Reload OS 1.5.1 (app interface 2). The descriptions are the header's own comments.

Threading: every LVGL call happens inside an LVGL callback (event, timer - they run on the LVGL task) or between ros_lock() / ros_unlock(). Nothing that waits belongs on the LVGL task - see the rules.

ros_task_endfunction

The end of a task that counts itself in *live (an app on the SD card must, see ros_elfapp_t.tasks): the count goes down here, in the firmware, so the task never returns into code that may be gone. caps: the task was made with xTaskCreate...WithCaps. Does not return.

ros_app_rtcfunction

Memory that keeps its contents through a restart (a crash, the watchdog, esp_restart(), the USB port opened) but not a power loss: RTC memory the firmware lends to apps, which have none of their own (an app's variables are in PSRAM and fresh at every load). A piece per name, the same place at every call with the same name and size; zeros the first time and after a power loss - check the contents (a checksum of your own). 512 bytes in all, 4 names; NULL when none is left. LVGL task.

ติดตั้ง

ติดตั้ง Reload OS จากเบราว์เซอร์

เลือกบอร์ด เสียบสาย USB แล้วกด Install เบราว์เซอร์จะเขียน Reload OS ลงบอร์ดให้ ไม่ต้องดาวน์โหลดหรือติดตั้งโปรแกรมใด ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ (Windows, macOS, Linux)

  1. เลือกบอร์ด

    image ของบอร์ดไหนใช้ได้กับบอร์ดนั้นเท่านั้น ทาง USB ไม่มีอะไรกันการเขียนผิดบอร์ด: บอร์ดจะเปิดมาจอมืด และเขียน image ที่ถูกต้องทับก็กลับมาใช้ได้

    กำลังโหลดรายการ…

  2. เสียบสาย

    เลือกบอร์ดก่อน: ช่อง USB ที่ต้องใช้ขึ้นกับบอร์ด

    เสียบช่อง USB Type-C ของตัวชิปเอง (USB Serial/JTAG) เข้าคอมพิวเตอร์ ในรายการของเบราว์เซอร์จะชื่อ "USB JTAG/serial debug unit"

    เสียบช่อง UART ของบอร์ด (ชิป USB-serial CH340 หรือ CH343) เข้าคอมพิวเตอร์ ในรายการของเบราว์เซอร์จะชื่อ "USB Serial" ถ้าไม่ขึ้น คอมพิวเตอร์ต้องลงไดรเวอร์ของชิป - ตัวติดตั้งมีลิงก์ให้ การเขียนผ่านชิปนี้ใช้เวลาหลายนาที

    บอร์ดไม่ตอบ: กด BOOT ค้างไว้ แตะ RESET ปล่อย BOOT แล้วกด Install อีกครั้ง

  3. ติดตั้ง

    ทุกอย่างในบอร์ดจะถูกลบ - firmware เดิมที่มากับบอร์ด การตั้งค่า และไฟล์ จากหน้านี้ใส่ firmware เดิมของผู้ขายกลับไม่ได้

    เบราว์เซอร์นี้เข้าถึงพอร์ต USB serial ไม่ได้ เปิดหน้านี้ใน Chrome หรือ Edge บนคอมพิวเตอร์ ตัวติดตั้งทำงานบนหน้า HTTPS เท่านั้น

หลังติดตั้ง

  • บอร์ดเริ่มใหม่ ขึ้นหน้าหลักในราว 5 วินาที
  • ขึ้น "Not activated" จนกว่าจะใส่ product key: Settings › About
  • flash drive ว่าง: แอปมาจาก Studio หรือ app kit
  • รุ่นถัดไป: Settings › About › Check online - ไม่ต้องใช้สาย

ควรรู้

  • ตัวติดตั้งคือ ESP Web Tools ที่เว็บนี้เก็บไว้เอง หน้าต่างของมันเป็นภาษาอังกฤษ
  • image คือ flash ทั้ง 16 MB เบราว์เซอร์ส่งแบบบีบอัด
  • ใช้บนมือถือ แท็บเล็ต Safari หรือ Firefox ไม่ได้: ไม่มี Web Serial
  • ดูระบบก่อน: ลองใช้ รันในเบราว์เซอร์

มีอะไรบ้าง

ทุกอย่างที่ตู้คีออสก์ต้องใช้ มีมาให้แล้ว

Reload OS เขียนด้วยภาษา C บน ESP-IDF และ LVGL ผลิตภัณฑ์ที่สร้างบนระบบนี้ได้ทุกอย่างด้านล่างตั้งแต่เริ่ม แล้วเพิ่มเฉพาะแอปของตัวเอง

หน้าจอสัมผัสที่พร้อมใช้

แถบสถานะ, หน้ารวมแอปที่ลากจัดลำดับได้, ตั้งค่าด่วน, ธีมมืดและสว่าง, คีย์บอร์ดบนจอปุ่มใหญ่พร้อมภาษาไทย, ปิดจอเมื่อไม่ใช้ - และแอปที่เปิดเองเมื่อเครื่องเริ่มทำงาน

แอปใหม่ ไม่ต้องลงเฟิร์มแวร์ใหม่

แอปคือไฟล์หนึ่งไฟล์ในโฟลเดอร์ apps/ บนแฟลชไดรฟ์ของเครื่องหรือการ์ด SD คัดลอก รีสตาร์ต แล้วแตะไอคอน ลูกค้าเขียนแอปเองได้ด้วย app kit

เชื่อมต่อได้ทุกทาง

Wi-Fi และ Bluetooth LE, Ethernet แบบ DHCP หรือกำหนด IP เอง, ฮอตสปอตที่แชร์อินเทอร์เน็ตของเครื่อง และเวลาจากเครือข่ายที่นาฬิกาแบตเตอรี่เก็บไว้

อุปกรณ์ USB

แฟลชไดรฟ์, คีย์บอร์ดและเครื่องสแกนบาร์โค้ด / QR, ตัวแปลงซีเรียล, เว็บแคม, เครื่องอ่านสมาร์ตการ์ด และเครื่องพิมพ์ใบเสร็จ - และใช้ตัวเครื่องเป็นไดรฟ์ USB ให้คอมพิวเตอร์ได้

ดูแลผ่านเบราว์เซอร์

ดูและสั่งงานหน้าจอจากเบราว์เซอร์พร้อมรหัสผ่าน, จัดการไฟล์ในทุกไดรฟ์, เปลี่ยนการตั้งค่า และอัปเดตเฟิร์มแวร์ผ่านเครือข่าย

ทำงานได้โดยไม่มีคนเฝ้า

อัปเดตที่ย้อนกลับเองได้, บันทึกทุกครั้งที่เครื่องขัดข้อง, safe mode เมื่อขัดข้องซ้ำ ๆ, watchdog เฝ้าหน้าจอ และทัชสกรีนที่ถูกปลุกกลับมาเมื่อหยุดตอบสนอง

หน้าตาเดียวกันทุกจอ

แนวนอน แนวตั้ง จอสี่เหลี่ยมจัตุรัส จอเล็ก

หน้าจอหลักและแอปชุดเดียวกันจัดวางตัวเองให้พอดีกับจอของแต่ละบอร์ดและทิศทางที่ติดตั้ง ภาพทั้งหมดคือ UI จริงที่เรนเดอร์ตามขนาดจอของแต่ละบอร์ด

เขียนแอปของคุณเอง

app kit สร้างแอปสำหรับเครื่อง Reload OS ได้โดยไม่ต้องมีซอร์สของเฟิร์มแวร์: ภาษา C, LVGL 9.2 กับ API ของ Reload OS, ESP-IDF 6.1 และคำสั่งเดียว

  • ใช้บริการของเฟิร์มแวร์ได้: หน้าจอ, เครือข่าย, ที่เก็บข้อมูล, เสียง, USB, เครื่องพิมพ์ และเครื่องอ่านบัตร
  • สร้างแยกตามบอร์ด และตรวจกับรายชื่อฟังก์ชันที่เฟิร์มแวร์เปิดให้ ก่อนถึงเครื่องจริง
  • ติดตั้งด้วยการคัดลอกไฟล์เดียว - จากเบราว์เซอร์, คอมพิวเตอร์ หรือการ์ด SD
